# ScienceQtech Employee Performance Mapping

## 📋 نظرة عامة على المشروع

مشروع تحليل بيانات الموظفين في شركة ScienceQtech الناشئة المتخصصة في علوم البيانات. يهدف المشروع إلى تحليل أداء الموظفين، حساب الرواتب والمكافآت، وإنشاء تقارير شاملة لدعم قرارات الموارد البشرية.

## 🎯 أهداف المشروع

- تحليل بيانات الموظفين واستخراج تقارير محددة
- حساب الحد الأقصى والأدنى للرواتب حسب الأدوار
- حساب المكافآت بناءً على تقييمات الأداء
- تصنيف الموظفين حسب الخبرة والأقسام
- إنشاء views و stored procedures لتسهيل الاستعلامات

## 🗂️ هيكل قاعدة البيانات

### الجداول الرئيسية:

1. **emp_record_table** - جدول بيانات الموظفين الرئيسي
2. **proj_table** - جدول المشاريع
3. **data_science_team** - جدول فريق علوم البيانات

## 📊 الاستعلامات المنفذة

### 1. إنشاء قاعدة البيانات والجداول
- إنشاء قاعدة بيانات `employee_final_Project_ScienceQtech`
- إنشاء الجداول مع العلاقات (Foreign Keys)

### 2. استعلامات تصفية البيانات
- تصفية الموظفين حسب التقييم (أقل من 2، أكثر من 4، بين 2 و 4)
- دمج الأسماء الأولى والأخيرة للموظفين في قسم المالية
- استخراج بيانات أقسام الرعاية الصحية والمالية باستخدام UNION

### 3. التحليلات المتقدمة
- حساب الحد الأقصى والأدنى للرواتب حسب الدور الوظيفي
- ترتيب الموظفين حسب الخبرة باستخدام RANK()
- استخدام Window Functions لحساب أعلى تقييم في كل قسم

### 4. Views والإجراءات المخزنة
- إنشاء view للموظفين براتب أكثر من 6000
- إنشاء stored procedure لاسترجاع الموظفين بخبرة أكثر من 3 سنوات
- إجراء مخزن للتحقق من المعايير الوظيفية

### 5. تحسين الأداء
- إنشاء index على عمود FIRST_NAME لتحسين الأداء

### 6. حساب المكافآت
- حساب المكافآت: `5% من الراتب × تقييم الموظف`

### 7. تحليل الرواتب
- حساب متوسط الرواتب حسب القارة والدولة

## 🚀 كيفية الاستخدام

### المتطلبات:
- MySQL Server 5.7 أو أحدث
- ملفات CSV: `emp_record_table.csv`, `proj_table.csv`, `data_science_team.csv`

### خطوات التنفيذ:

1. **إنشاء قاعدة البيانات:**
```sql
CREATE DATABASE employee_final_Project_ScienceQtech;
USE employee_final_Project_ScienceQtech;
```

2. **تنفيذ السكريبت:**
```bash
mysql -u username -p employee_final_Project_ScienceQtech < employee_performance_mapping.sql
```

3. **استيراد البيانات:**
- استورد ملفات CSV إلى الجداول المقابلة

## 📈 أمثلة على الاستعلامات

### حساب المكافآت:
```sql
SELECT EMP_ID, 
       CONCAT(FIRST_NAME, ' ', LAST_NAME) AS NAME,
       EMP_RATING,
       SALARY,
       (SALARY * 0.05) * EMP_RATING AS BONUS
FROM emp_record_table;
```

### الموظفين بخبرة أكثر من 10 سنوات:
```sql
SELECT EMP_ID, FIRST_NAME, LAST_NAME, EXP
FROM emp_record_table
WHERE EXP > 10
ORDER BY EXP;
```
